A little pregame briefing.

On iPhone, open in Safari. On Android, use Chrome. Tap Play. The game loads automatically.

Use the D-pad to skate and A / B / C for the game’s actions. Press START to advance the title screen or pause in-game. You can skate and press an action button at the same time.

The game menu has Pause, Restart, Save state, and Load state. Save state downloads a file; Load state lets you pick that file to resume. On iPhone, look in Files → Downloads. Save before leaving the page.

With a keyboard: arrow keys to skate, A / S / D for A / B / C, and Enter for START. Connected controllers can be mapped in the game menu.

With a controller: connect it, tap Play, and press a controller button while this page is active. Open the game menu → Control Settings to select it for Player 1 or change button mappings.

This prototype runs in the browser. An internet connection is required to load it.

Controller check

    If your controller appears here, close this check and select it for Player 1 in the game’s Control Settings. Press buttons or move a stick to see them register above.

    If it stays missing, reconnect the receiver or USB cable and try again with this page active. Controller details stay on your device.
